One script (``static/js/address-directory.js``) turns the street, postal code and town inputs into ARIA comboboxes. The fields stay authoritative: nothing here changes a field except a deliberate choice, or the town (postal code) that follows from a postal code (town) that has exactly one answer and goes into an empty field. The texts are read by the script from the data attributes; ``%(name)s`` placeholders are replaced there by plain string replacement and the result is set as text. Without JavaScript the panel and the notice stay empty and nothing is said about it (D-066).
